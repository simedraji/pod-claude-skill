# PODAcademy Course/Curriculum Template

Reusable structure for turning any reference-file topic above into a PODAcademy.com lesson, matching the user's known format: **one theory session (≈1 hour) + one practical session (≈1 hour)** per module.

## Suggested module sequence (beginner → advanced)

1. **POD Fundamentals** — what POD is, platform landscape (`platforms-fulfillment.md`), choosing your first stack
2. **Niche & Keyword Research** — Identity × Interest framework, validation checklist, tools (`niche-keyword-research.md`)
3. **Design Basics** — tool stack, design principles, AI prompt workflow, IP safety (`design-ai-tools.md`)
4. **Listing & SEO** — Etsy SEO 2026 rules, title/tag/photo/video strategy (`seo-marketing.md`)
5. **Pricing & Fees** — Etsy fee math, margin framework (`marketplace-fees-affiliate.md`, `automation-finance.md`)
6. **TikTok Shop & Affiliate Marketing** — commission modeling, fulfillment rules, content strategy (`marketplace-fees-affiliate.md`, `seo-marketing.md`)
7. **Selling on Plusbase / TikTok dropship workflow** — verify current TikTok logistics mandate live before teaching this module, it has changed multiple times in 2026
8. **Automation** — n8n/Zapier/Make blueprints, AI-assisted listing pipeline (`automation-finance.md`)
9. **Finance & Scaling** — KPI dashboard, multi-channel strategy, seasonal calendar planning (`automation-finance.md`, `niche-keyword-research.md`)

## Per-module lesson template

```
# Module [N]: [TITLE]

## Theory session (60 min)
- Learning objectives (2-3 bullet points)
- Core concept explanation (pull from the matching reference file)
- 2026-specific updates students must know (flag anything time-sensitive — fees, algorithm
  changes, platform policy shifts — and note "verify current status" where the reference
  file says rules have changed recently)
- Common beginner mistakes

## Practical session (60 min)
- Step-by-step hands-on exercise (e.g., "research 3 micro-niches using EverBee", "write
  one Etsy listing using the SEO prompt template")
- Checklist/SOP handout (from `automation-finance.md` SOP template, adapted to the module)
- Homework/deliverable before next session
```

## eBook chapter template
Same structure minus the "session" framing — Concept → 2026 updates → Examples → Checklist → Action steps.

## Note on freshness
Whenever drafting new course content from this skill, flag any number (fee %, commission rate, algorithm rule) that the reference files mark as "verify before teaching" — these are exactly the facts most likely to have shifted again since June 2026.
